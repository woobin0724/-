# AI Job Pass Finder

마이스터고 학생의 스펙(내신 등급 · 자격증)과 실제 기업의 요구 역량을 매칭해주는
취업 컨설팅 플랫폼입니다. **전북기계공고 E.M.P 팀**이 NAVER OGQ마켓 AI 공모전 출품을 위해 제작했습니다.

---

## 1. 실행 방법

### 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Streamlit Community Cloud 배포
1. 이 저장소(`app.py`, `requirements.txt` 포함)를 GitHub에 push
2. [share.streamlit.io](https://share.streamlit.io) 접속 → New app
3. Repository / Branch / `app.py` 경로 지정 후 Deploy
4. 별도의 Secrets나 API 키 설정 없이 바로 구동됩니다 (백업 데이터로 동작 보장)

## 3. 스크래핑한 외부 데이터 출처

| 출처 | URL | 수집 항목 | 비고 |
|---|---|---|---|
| 한국산업인력공단 Q-Net | https://www.q-net.or.kr | 국가기술자격(기능사) 종목·직군 정보 | 실시간 스크래핑 시도 → 실패 시 백업 데이터 사용 |
| 링커리어 (Linkareer) | https://linkareer.com | 기업 채용 공고, 직무 요구사항 | 실시간 스크래핑 시도 → 실패 시 백업 데이터 사용 |

### 안내 및 주의사항
- 두 사이트 모두 **robots.txt 및 이용약관을 준수**하는 범위 내에서 스크래핑해야 합니다.
  상업적/비영리적 목적에 관계없이 배포 전 반드시 각 사이트의 최신 이용약관을 확인하세요.
- 실시간 스크래핑이 실패(구조 변경, 접속 차단, 타임아웃 등)할 경우를 대비해
  **`app.py` 내부에 20건의 백업(가상) 기업 데이터**를 내장했습니다. 이 백업 데이터는
  실제 기업 채용 공고를 그대로 복제한 것이 아니라, 마이스터고 취업 트렌드를 반영해
  **팀에서 구성한 예시 데이터**입니다.
- 향후 안정적인 실서비스 운영을 위해서는 Q-Net Open API, 워크넷(Work-Net) 채용정보
  Open API 등 **공식 API 연동으로 전환**하는 것을 권장합니다.

## 4. 핵심 로직 요약

- **내신 환산**: 마이스터고 5등급 성취평가제(1.0~5.0등급)를 100점 만점으로 선형 환산
  (1.0등급 = 100점, 5.0등급 = 0점)
- **취업 합격 지수** = 내신 환산 점수 × 50% + 자격증 가산점(기업 요구 자격증 일치율) × 50%
- **AI 피드백**: 기업별 요구 등급·자격증 대비 사용자의 강점/부족한 점을 1:1로 안내
- **예외 처리**: 스크래핑 함수는 `try/except`로 감싸 실패 시 자동으로 백업 데이터를 반환
